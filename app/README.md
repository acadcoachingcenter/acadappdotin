# ACAD Online Coaching -- Frontend

React + Vite SPA for acadapp.in. Originally generated by base44; now talks to a
self-hosted Cloudflare Worker API (see `../worker`) instead of base44's backend.

See `MIGRATION_GUIDE.md` in the parent folder for full setup and deploy steps.

## Local dev
```
npm install
cp .env.example .env   # set VITE_API_BASE to your worker's local/deployed URL
npm run dev
```
